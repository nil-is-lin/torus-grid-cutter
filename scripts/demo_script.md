# 演示视频录制脚本

目标：1–3 分钟操作演示，覆盖核心功能闭环。
窗口建议 1280×720（README 嵌入宽度 720），用 `cargo run --release` 启动。

## 分镜

| 时间 | 操作 | 画面重点 |
|---|---|---|
| 0:00–0:10 | 启动程序，默认 Quad 网格（40×40） | 3D 环面、标题栏 |
| 0:10–0:20 | 切换到 Planar UV 视图 | UV 展开平面网格 |
| 0:20–0:35 | 左键拖动旋转 3D 视图，滚轮缩放 | 相机轨道 |
| 0:35–0:50 | 切回 3D 视图；Mesh 页调整 R=2.5、r=0.8 | 环面形状实时变化 |
| 0:50–1:10 | 切换 Delaunay 网格（点数 800），拖动 R/r | 三角网格流畅重建（拓扑缓存） |
| 1:10–1:30 | Cut 页：U/V 各 4 条切割线 → Apply | 网格沿切割线切开、区域划分 |
| 1:30–1:50 | 切换到 Knot 模式：k1=2, k2=3 → Apply | knot 切割曲线 |
| 1:50–2:10 | 右侧 Display 面板：By Region 配色 + 切换配色方案 | 区域着色 |
| 2:10–2:25 | Shader 页：逐补片材质/着色器 | 补片级外观 |
| 2:25–2:45 | Export 页：导出 OBJ（整体 + 按补片） | 文件输出 |
| 2:45–3:00 | 展示导出文件（资源管理器） | 收尾 |

## 录制工具

- Windows：Win + G（Game Bar）或 OBS Studio
- 结束后用剪映/ffmpeg 裁剪片头片尾，导出 H.264 mp4（≤50MB 为宜）

## 发布

1. 文件命名 `demo.mp4`
2. 上传到 GitHub Releases（tag v0.1.0 时一并上传），或 Bilibili / YouTube
3. 把链接填进 README「演示视频」小节（模板已就位）
